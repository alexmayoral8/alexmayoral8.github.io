Shoulder Rehabilitation Game Based on Flappy Bird

Game designed to motivate repetitive shoulder exercises using arm movement as the primary control method.

Project Overview

This project adapts the mechanics of Flappy Bird to support shoulder rehabilitation exercises. Instead of controlling the character with a keyboard or mouse, the user moves their arm and receives real-time visual feedback within the game.

The goal was to create a low-cost, motivating and interactive tool that would help convert repetitive therapeutic movements into a more engaging experience for the user.

Accelerometer control

An accelerometer is placed on the arm near the elbow to estimate orientation of the arm and the angle of shoulder abduction. The abduction elevates the character and adduction makes it descend.

Camera-based control

The system can also function with computer vision. A camera detects arm movement in real-time, eliminating the need for portable sensors.

Calibration System

Before playing, a calibration routine was implemented to adapt the game to users with different ranges of motion. The user lowers the arm as far as possible and then raises it to their comfortable limit. These positions are saved as minimum and maximum, and the game maps the user's available movement to the character's movement range.
